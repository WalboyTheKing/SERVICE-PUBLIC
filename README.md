# Marketplace Pi Network (Next.js 14 + Supabase + Pi SDK)

Marketplace complète pour Pi Network, intégrant l'authentification native, un système de vendeurs certifiés et la publication d'annonces payantes vérifiées par serveur.

## 🚀 Fonctionnalités
- **Authentification Pi Network** via `Pi.authenticate()`.
- **Système de Vendeur Permanent** à 0.01 π.
- **Frais de Publication d'Annonce** à 0.001 π.
- **Vérification Serveur** complète de toutes les transactions avec l'API REST v2 Pi Network.
- **Stockage d'images** via Supabase Storage Buckets.

## 🛠️ Installation Locale

1. Exécutez :
```bash
npm install
```

2. Créez un fichier `.env.local` basé sur `.env.example`.

3. Lancez en local :
```bash
npm run dev
```
